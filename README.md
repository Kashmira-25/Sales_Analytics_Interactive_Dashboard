# 📊 Sales Analytics Interactive Dashboard


## Overview

An end-to-end e-commerce sales analytics dashboard analyzing
50,000+ transactions to generate business insights.

The project performs data cleaning, feature engineering,
customer segmentation, product analysis and operational analytics.


## Features

### Sales Analytics
- Revenue trends
- Profit analysis
- Monthly performance
- Growth analysis


### Customer Analytics
- Customer segmentation using RFM analysis
- Customer value analysis
- Demographic analysis


### Product Analytics
- Top performing products
- Category analysis
- Profitability analysis


### Operations Analytics
- Order status analysis
- Payment analysis
- Shipping analytics


## Tech Stack

- Python
- Pandas
- NumPy
- Plotly
- Streamlit


## Dataset

50,000+ e-commerce transactions containing:
- Customer details
- Product information
- Sales transactions
- Payment details
- Order operations
